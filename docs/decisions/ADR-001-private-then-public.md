# ADR-001: Private now, public at release, under the Foundation's org

## Context
The program requires open-source release. The team needs a private working space until the
expression of interest is submitted and the construct has been through expert review.

## Decision
The repo is private under `JeremyGracey-AI` during the build and application. Before public
release it is transferred to The Gerontechnology Foundation's GitHub organization. Code is
Apache-2.0; scenarios, rubric, and labels are CC BY 4.0.

## Consequences
Everything committed now is written as if public: no keys, no real-person data, no
harmful specifics in answer keys. The transfer is a one-time settings action, not a rewrite.
